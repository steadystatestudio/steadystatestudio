# Steady State Studio

Free, focused desktop tools for Windows and Linux. Local files, clear controls, useful results.

**[Explore the Studio](https://steady-state-studio.com/)**

- **File Renamer** — Preview filename changes, rename a batch, and undo the last batch. [App details](https://steady-state-studio.com/apps/file-renamer/) · [GitHub](https://github.com/steadystatestudio/file-renamer-releases)
- **Square Photo Padder** — Make photos square with padding while keeping the full image. [App details](https://steady-state-studio.com/apps/square-photo-padder/) · [GitHub](https://github.com/steadystatestudio/square-photo-padder-releases)
- **Contact Sheet Maker** — Turn local photos into printable PDF or JPEG contact sheets. [App details](https://steady-state-studio.com/apps/contact-sheet-maker/) · [GitHub](https://github.com/steadystatestudio/contact-sheet-maker)
- **PDF Prep** — Prepare one PDF from PDFs and photos, arrange pages, and check its file size before saving. [App details](https://steady-state-studio.com/apps/pdf-prep/) · [GitHub](https://github.com/steadystatestudio/pdf-prep)

Worked guides: [Make photos square without cropping](https://steady-state-studio.com/guides/make-photos-square-without-cropping/) · [Create a printable photo contact sheet](https://steady-state-studio.com/guides/create-printable-photo-contact-sheet/)

Have a repetitive task that could use a small tool? [Share an idea](https://steady-state-studio.com/contact/). Describe the task, your current steps, and the result you need.

All features are free. [Donations on Ko-fi](https://ko-fi.com/steadystatestudio) are optional.
